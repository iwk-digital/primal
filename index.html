Welcome to Primal, the Platform for Review and Interaction with Music Annotation Linked-data. This platform provides human-readable views over Linked Data structures adhering to the Web Annotation Data Model and/or the Music Annotation Ontology, visualising textual content, targeted MEI fragments (rendered as digital scores using Verovio), audio examples (rendered using WaveSurfer.js), as well as a graph view and formatted code listing of the underlying Linked Data structure.

To use Primal, simply append the URI of a Web-hosted (and CORS-compliant) music annotation Linked Data resource to the URL of this page using the ?obj query parameter, e.g.: 

https://primal.mdw.ac.at/?obj=https://raw.githubusercontent.com/Signature-Sound-Vienna/data/TISMIR/annot/oa/ExDonau.jsonld

If you are using Primal to publish a collection of music annotations, perhaps to provide supporting evidence in scholarly dissemination, you may find it convenient to register proxy URIs that implement content negotiation, with a redirection service such as https://w3id.org to forward your readers here. This way, requests from a browser can be forwarded to Primal for visualisation, whereas requests from machines can be forwarded to the original resource. For example, the following link provides such a proxy to the one used above: 

https://w3id.org/ssv/TISMIR/annot/oa/ExDonau
